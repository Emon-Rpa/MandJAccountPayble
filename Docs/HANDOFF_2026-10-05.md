## Goal
Four banks (SCB, CITI, HSBC, Dhaka Bank = `DB`) in one organised, maintainable pipeline.
**Milestone 1:** statement arrives by mail as xlsx (one sheet, a different layout per bank) -> every row goes into the shared 22-column `DATA_PREPARATION` format -> for each debit row, find the advice mail, download it, prepare data from the advice.
ERP (Oracle) entry for the non-SCB banks is a later milestone.

## Findings (from the real data)

**Statements** (`statements/*.xlsx`, split from `BANKSTATEMENT.xlsx`):
- Header fingerprints: SCB = Account Number/Account Name/Address/Description/Withdrawal/Deposit/Balance. CITI = Branch Number/Bank Reference/Transaction Description/Cheque Amount/Transaction Amount/Customer Reference. HSBC = Bank reference/TRN type/Post date/Credit amount/Debit amount/Closing ledger balance. DB = TXN DATE/VALUE DATE/TXN BRN/DESCRIPTION/DEBIT/CREDIT/BALANCE, with the header on row 2.
- DB sheet row 121 has about nine transactions pasted into one cell (no amounts). It is skipped. Some DB rows have text dates `dd-MM-yyyy`.
- CITI has 114 balance-only rows with no value date (falls back to Statement Date).

**Mapping used for non-SCB banks:** `LC_NUMBER` = the bank's own reference (Bank Reference / Bank reference / first token of the DB description). `BANK_DC_NO` = Customer reference (blank if `NONREF` or the same as the bank reference). `TO_ACCOUNT` as shown in the statement. DB has no account or currency in the sheet.

**Mailbox `rpa_center@mj-group.com`** (one Inbox, about 19,000 mails, Jan 2025 - Oct 2026, no subfolders). Tested on sample statement rows:
- CITI 8/14 matched. Senders: `tradeservice.bangladesh@citi.com` (`Debit Advice - <bank ref>`, `ADB.pdf`) and `paylink.asia@citi.com` (`(Secure)Citibank Debit Advice - ... ref<ref>`, RTGS, includes a `message.pdf`). Some lines had no mail at all.
- HSBC 11/14 matched. Sender `HSBC Advising Service`. About 30% of its mails are "REGISTERED" notices with no attachment. Export collection lines had no mail.
- DB 0/14 by subject or body. The full reference (e.g. `1418250403191B01`) is inside the PDF of the `Advice for IBCPA <doc>` mail from `DHAKABANK`, received on the statement date. This held for 3/3 import-bill rows. Only import bill liquidation has a verified advice type.
